# feel — трекер эмоций

PWA для iPhone: отметка эмоций по русской сетке «энергия × приятность» (144 слова)
и два уведомления в день — утром про план, вечером про итоги дня.
Адрес: feel.meowtreach.com, хостинг reg.ru (shared).

**Статус:** этап 1 «Ядро» готов и ждёт проверки на живом iPhone.
Этапы 2 (медиа, аналитика, xlsx) и 3 (офлайн-черновики, резервные копии) не начаты:
по ТЗ следующий этап начинается после проверки предыдущего.

## Что есть в этапе 1

- Вход по email и паролю (argon2id, 5 попыток за 15 минут, сессия 90 дней
  в HttpOnly-cookie, CSRF). Регистрация закрыта, пользователя создаёт консольная команда.
- Оболочка PWA: manifest, service worker, иконки, заставки запуска, безопасные зоны,
  светлая и тёмная темы, «Уменьшение движения».
- Инструкция по установке, если приложение открыто в Safari.
- Сетка 12×12: прокрутка во все стороны, приближение щипком и кнопками,
  насыщенность по `intensity`, карточка слова с описанием.
- Отметка за три касания: квадрант → слово → «Сохранить». Через «Дальше» — метки
  «С кем / Где / Чем занят» (можно добавить свою), заметка, другое время записи.
- Экраны «Сегодня», «Утро» (план, «Напомнить через 30 минут», сон),
  «Вечер» (план, вечерняя отметка, итоги, спорт), «Дневник» (по дням, фильтры,
  правка и удаление), «День», «Настройки».
- Уведомления Web Push (VAPID, pywebpush): время, тексты, повтор через N минут,
  часовой пояс, статус подписки, «Отправить тестовое». Рассылка по cron раз в 5 минут.
- 56 автотестов сервера, среди них: пользователь Б не видит и не меняет данные
  пользователя А; правила рассылки (дубли, повтор, опоздание больше 2 часов,
  часовые пояса, удаление подписки по 410).

Вкладка «Аналитика» пока показывает заглушку. Фото, голос и выгрузка в xlsx — этап 2.

## Структура

```
app/
  main.py            FastAPI: API, заголовки безопасности, раздача static/
  config.py          настройки из .env
  db.py, models.py   SQLite (WAL), 11 таблиц из ТЗ + login_attempts
  security.py        пароли, сессии, CSRF, ограничение попыток входа
  routers/           auth, journal (эмоции, отметки, дни, дневник, метки), prefs (настройки, push)
  services/          notify.py (правила рассылки), push.py, days.py, users.py, emotions.py
  cli.py             create-user, set-password, gen-vapid, send-due
migrations/          Alembic; 0002 загружает data/emotions.json
data/emotions.json   справочник эмоций
static/              PWA: index.html, sw.js, css/, js/ (модули без сборки), icons/
deploy/              passenger_wsgi.py, crontab, проверка хостинга
tests/               pytest
tools/make_icons.py  генерация иконок и заставок (нужен Pillow, только для разработки)
```

## Локальный запуск

```bash
python3 -m venv venv && . venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env    # заполнить SECRET_KEY; для http://localhost добавить
                        # COOKIE_SECURE=false и FORCE_HTTPS=false
alembic upgrade head
python -m app.cli create-user you@example.com
uvicorn app.main:app --reload
pytest
```

Уведомления локально не проверить: iOS шлёт их только установленному с HTTPS-адреса приложению.

## Развёртывание на reg.ru

Схема как у ПодСчёта (`money_app`): Python-приложение под Passenger. В `money_app` файл
`passenger_wsgi.py` не попал в репозиторий, поэтому здесь он написан заново:
`deploy/passenger_wsgi.py`. FastAPI работает через WSGI-обёртку `a2wsgi`.

1. Проверить хостинг по SSH: `sh deploy/check_hosting.sh`. Нужны Python 3.9 или новее,
   ставящийся пакет `cryptography`, cron раз в 5 минут и место на диске.
2. Создать сайт feel.meowtreach.com в панели, включить Python, выпустить сертификат Let's Encrypt.
3. Положить проект **вне публичной папки** сайта:
   ```bash
   cd ~ && git clone https://github.com/thomaskroppas/feel.git feel && cd feel
   python3 -m venv venv && venv/bin/pip install -r requirements.txt
   cp .env.example .env
   venv/bin/python -c "import secrets; print(secrets.token_hex(32))"   # → SECRET_KEY в .env
   venv/bin/python -m app.cli gen-vapid                                # → ключи VAPID в .env
   venv/bin/alembic upgrade head
   venv/bin/python -m app.cli create-user you@example.com --admin
   ```
4. В корень сайта (например, `~/www/feel.meowtreach.com/`) скопировать только
   `deploy/passenger_wsgi.py`: Passenger на reg.ru запускает его сам, `.htaccess` не нужен
   (директивы Passenger там запрещены). `passenger_wsgi.py` переключается на `~/feel/venv`.
   В настройках сайта в панели включить «Перенаправлять HTTP-запросы в HTTPS», а в `.env`
   оставить `FORCE_HTTPS=false`: https обрабатывает nginx, приложению запросы приходят по http.
5. Добавить задание cron из `deploy/crontab.example`.
6. Открыть сайт в Safari на iPhone → «Поделиться» → «На экран „Домой“» → войти →
   «Включить уведомления» → в настройках «Отправить тестовое».

**Без SSH, через веб-shell в панели reg.ru.** Команды те же. Пароль передавайте через
переменную, если скрытый ввод не работает: `FEEL_PASSWORD='пароль' venv/bin/python -m app.cli create-user you@example.com --admin`,
затем `history -c`. Долгие команды (`pip install`) запускайте в фоне с записью в файл:
`nohup venv/bin/pip install -r requirements.txt > var/pip.log 2>&1 &`. Задание cron
добавляется в разделе «Планировщик» панели.

**Обновление:** `git pull && venv/bin/pip install -r requirements.txt && venv/bin/alembic upgrade head`,
затем перезапуск Passenger (`touch tmp/restart.txt` в корне сайта или кнопка в панели).
При изменениях в `static/` поднимите `VERSION` в `static/sw.js`, чтобы на телефоне сменился кэш.

База (`var/feel.db`) и подписки лежат на диске, поэтому перезапуск приложения ничего не теряет.

## Отступления от ТЗ и решения по умолчанию

- **Таблица `login_attempts`** (двенадцатая). Ограничение «5 попыток за 15 минут» хранится в
  базе, а не в памяти: Passenger может держать несколько процессов.
- **Поле `day_logs.plan_remind_at`** хранит время для «Напомнить через 30 минут». Это
  напоминание отправляется, если план так и не записан.
- **«Удалить все данные»** стирает отметки, дни, метки, медиа, журнал уведомлений и
  возвращает настройки к значениям по умолчанию; учётная запись и подписки остаются.
  Подтверждается паролем.
- **Метки:** удалить можно только метку, которой нет в записях; использованную — только скрыть.
- **Уведомление «нет подписок»** тоже пишется в журнал, повтора после него не будет.
- **Вечерняя отметка** — это отметка с экрана «Вечер» (`source = evening`). Обычная отметка
  днём вечернее уведомление не отменяет.
- **Цвет дня при равенстве квадрантов** — квадрант более поздней отметки.
- **Сон** вводится с шагом 0,5 часа от 0 до 16; **время уведомлений** — с точностью до минуты,
  повтор — от 15 до 240 минут.
- **Python 3.9+** (тесты проходят на 3.9 и 3.13).
